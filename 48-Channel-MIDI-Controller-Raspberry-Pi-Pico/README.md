# Kontroler MIDI z 48 potencjometrami – Raspberry Pi Pico

Projekt elektronicznego kontrolera MIDI wyposażonego w 48 potencjometrów, przeznaczonego do sterowania parametrami urządzeń i oprogramowania muzycznego.

Urządzenie zostało opracowane na indywidualne zamówienie klienta.

**Główne rozwiązania:**
- Mikrokontroler Raspberry Pi Pico (RP2040).
- 48 potencjometrów do regulacji parametrów.
- Multipleksery analogowe CD74HC4067.
- Odczyt sygnałów analogowych.
- Dwie współpracujące płytki PCB.
- Komunikacja MIDI.

**Zakres wykonanych prac:**
- Opracowanie schematów elektronicznych.
- Dobór komponentów.
- Projektowanie dedykowanych płytek PCB.
- Przygotowanie plików produkcyjnych.
- Integracja układów elektronicznych.
