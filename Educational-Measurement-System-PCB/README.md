# Modułowy system pomiarowy – projekt dydaktyczny

Projekt płytki PCB opracowany na indywidualne zamówienie na potrzeby zajęć dydaktycznych dla studentów uczelni technicznej.

Układ został zaprojektowany jako platforma do integracji mikrokontrolera, czujników oraz modułów pomiarowych i zasilających.

## Główne elementy projektu

- Mikrokontroler ESP32.
- Czujnik temperatury, wilgotności i ciśnienia BME280.
- Moduły pomiarowe INA3221.
- Układ monitorowania poziomu naładowania akumulatora MAX17043.
- Moduł zarządzania energią MCP73871.
- Przetwornica napięcia TPS63070.
- Interfejs do podłączenia wyświetlacza LCD.
- Złącza do integracji dodatkowych modułów.

## Zakres wykonanych prac

- Opracowanie schematu elektronicznego.
- Dobór komponentów i modułów.
- Projektowanie dedykowanej płytki PCB.
- Rozmieszczenie elementów i prowadzenie ścieżek.
- Przygotowanie plików produkcyjnych PCB.
